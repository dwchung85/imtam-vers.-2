# 내 가입 정보 프로필 사진 개선

## 변경 내용
- 프로필 사진을 타일 중앙에 배치합니다.
- 사진 옆에 중복 표시되던 이름을 삭제합니다.
- 프로필 사진의 검정 테두리를 제거합니다.
- 수정 상태에서 프로필 사진을 눌러 새 이미지를 선택할 수 있게 합니다.
- 선택한 이미지를 화면에 미리 보여주고, 저장 시 가입 정보와 함께 데이터베이스에 반영합니다.
- 저장 직후 상단 사용자 사진에도 새 이미지가 표시되도록 현재 사용자 정보를 갱신합니다.

## 기술 세부사항
- 이미지 파일만 허용하고 브라우저에서 적정 크기와 용량으로 압축한 뒤 기존 프로필의 사진 값에 저장합니다.
- 취소하면 사진을 포함한 모든 변경 사항을 저장 전 상태로 되돌립니다.
- 사진 선택 및 저장 실패 안내 문구는 중앙 문구 파일에서 관리합니다.
- 모바일과 데스크톱에서 중앙 정렬과 입력 동작을 확인합니다.
